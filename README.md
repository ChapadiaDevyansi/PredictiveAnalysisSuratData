# Predictive Analytics System for Website Readiness Analysis

## 📌 Project Overview

This project was developed as part of the **Week 4 Internship**. It analyzes local businesses in Surat and predicts whether a business requires a website using machine learning. The project includes data preprocessing, exploratory data analysis, Power BI dashboards, and a Streamlit web application.

---

## 🎯 Objectives

- Analyze the digital presence of local businesses.
- Predict businesses that require a website.
- Compare machine learning models.
- Generate meaningful business insights.

---

## 🛠️ Technology Stack

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Power BI
- Streamlit

---

## 🤖 Machine Learning Models

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 60.43% |
| Decision Tree | **92.81%** |
| Random Forest | 92.09% |

**Best Model:** Decision Tree (92.81% Accuracy)

---

## 📊 Dashboard Features

- Business Overview
- Predictive Model Results
- Business Opportunity Analysis
- Business & Machine Learning Insights

---

## 💡 Key Insights

- 77.42% of businesses do not have a website.
- Decision Tree achieved the highest prediction accuracy.
- Customer reviews are the most important feature.
- Highly rated businesses without websites have strong digital growth potential.
